## My Learning Approach

My approach is focused on **learning by building**.

For each project, I try to:

1. Understand the requirements
2. Plan the project structure
3. Learn the concepts required
4. Implement the project
5. Test and debug the functionality
6. Improve the user interface and code structure
7. Document the project
8. Upload and organize it on GitHub
9. Review what I learned and identify what to improve next

This allows me to gradually develop both technical skills and practical development habits.
